# Fruit Yogurt Cooking Game

A three-round children’s cooking and English-vocabulary game built with HTML5, CSS3, and vanilla JavaScript.

## Run

Open `index.html` in a modern browser. No build step or web server is required.

For best browser audio behavior, press **Start Game** before interacting. The included version uses browser speech synthesis for English fruit pronunciation and Web Audio for music and sound effects, so it works without external audio files.

## Folders

- `assets/images/` — normalized game artwork made from the supplied asset pack
- `assets/audio/` — optional external pronunciation/effect files can be placed here later
- `assets/music/` — optional external background music can be placed here later

## Optional external audio names

Pronunciation: `apple.mp3`, `banana.mp3`, `grapes.mp3`, `mango.mp3`, `kiwi.mp3`, `strawberry.mp3`, `blueberry.mp3`

Effects: `correct.mp3`, `wrong.mp3`, `fruit-drop.mp3`, `drag.mp3`, `cut.mp3`, `ingredient-drop.mp3`, `mix.mp3`, `round-complete.mp3`, `game-complete.mp3`

Music: `background-music.mp3`

The current game intentionally generates audio in JavaScript, so these optional files are not required.
