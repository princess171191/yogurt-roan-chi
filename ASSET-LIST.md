## Optional external audio
The supplied game works without audio files by using browser speech synthesis and generated Web Audio sounds. These filenames can be added later if the audio layer is customized:

- Fruit pronunciation: `apple.mp3`, `banana.mp3`, `grapes.mp3`, `mango.mp3`, `kiwi.mp3`, `strawberry.mp3`, `blueberry.mp3`
- Effects: `correct.mp3`, `wrong.mp3`, `fruit-drop.mp3`, `drag.mp3`, `cut.mp3`, `ingredient-drop.mp3`, `mix.mp3`, `round-complete.mp3`, `game-complete.mp3`
- Music: `background-music.mp3`
